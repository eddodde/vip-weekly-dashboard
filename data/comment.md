4. 예상 질문 대비
- "객단가는 고객수가 줄어서 오른 것 아닌가"
  → 전사·비VIP 기준으로는 맞음(구성효과 90%). 단 VIP는 반대 —
    구매고객이 +1.3%로 늘었는데 객단가도 올랐고, 등급 구성효과는 오히려 마이너스.
    주문단가(+9.2%)는 분모가 주문건수라 고객수 감소 논리가 적용되지 않음
- "대시보드 구매고객 △12%는 뭔가"
  → 대시보드는 일평균·총결제 기준(구매일 단위 중복 집계). 월간 순고객 기준 VIP는 +1.3%.
    실제로 줄어든 것은 구매 빈도(인당 2.24→2.11건)
- "엘페스타 잘된 것 아닌가"
  → 거래액 +1.4%는 지켰으나 구매고객 △14.4%. 객단가 단독 방어 구조
- "8월 실적이 나쁜 것 아닌가"
  → 총결제 기준 △0.7%이나 순결제 기준 +4.7%. 차이는 반품 감소분

5. 지표 사용 주의 (혼용 금지)
- 대시보드 = 일평균 × 총결제 / 등급·고객단위 추출 = 월간 누적 × 순결제
- 두 기준을 같은 문장에서 섞지 말 것. 한 자료 안에서는 하나로 통일
- 대시보드의 '고객수'는 순고객이 아니라 일별 집계, '객단가'는 인당이 아니라 구매일당
